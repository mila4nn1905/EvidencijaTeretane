 EvidencijaTeretane

Java konzolna aplikacija za vođenje evidencije o članovima teretane, trenerima, treninzima i članarinama.

 Funkcionalnosti

- Dodavanje članova teretane
- Dodavanje trenera
- Prikaz svih članova i trenera
- Dodavanje i prikaz treninga
- Evidencija i plaćanje članarina
- Brisanje članova na osnovu broja članske karte

 Korišćene tehnologije

- Java
- Eclipse IDE
- Git i GitHub

 Objektno-orijentisano programiranje

Projekat koristi osnovne koncepte objektno-orijentisanog programiranja:

- Enkapsulacija
- Nasleđivanje
- Polimorfizam
- Apstraktne klase
- Interfejsi
- Kolekcije (`ArrayList`)

 Pokretanje aplikacije

1. Preuzeti ili klonirati repozitorijum.
2. Otvoriti projekat u Eclipse IDE-u.
3. Pokrenuti klasu `Main.java`.
